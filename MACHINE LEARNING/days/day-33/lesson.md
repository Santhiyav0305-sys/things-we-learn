# Day 33 — Hyperparameter tuning

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    Hyperparameters are settings chosen outside ordinary parameter fitting. Grid search tries a defined set; randomized search samples combinations.

Tune only after establishing a baseline and choose the metric before looking at results.

    ## Practice loop
    1. Read this lesson once.
    2. Run `starter.py`.
    3. Change one thing and predict what will happen.
    4. Complete the exercises without copying the solution.
    5. Write a short reflection in `progress/day-33.md`.
