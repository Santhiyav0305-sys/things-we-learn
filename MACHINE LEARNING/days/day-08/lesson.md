# Day 08 — Matplotlib visualization

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    Visualization helps you inspect distributions, relationships and outliers.

Learn line plots, scatter plots, bar charts, histograms, labels, titles and legends. A plot should answer a question rather than exist only for decoration.

    ## Practice loop
    1. Read this lesson once.
    2. Run `starter.py`.
    3. Change one thing and predict what will happen.
    4. Complete the exercises without copying the solution.
    5. Write a short reflection in `progress/day-08.md`.

    ## Checkpoint
    You are ready to move on when you can explain:
    - What problem this concept solves.
    - One example of when to use it.
    - One common mistake.
