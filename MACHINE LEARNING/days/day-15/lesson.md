# Day 15 — Classification and logistic regression

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    Classification predicts classes. Logistic regression produces probabilities and then class decisions using a threshold.

Learn accuracy, precision, recall and F1. Accuracy alone can be misleading with imbalanced classes.

    ## Practice loop
    1. Read this lesson once.
    2. Run `starter.py`.
    3. Change one thing and predict what will happen.
    4. Complete the exercises without copying the solution.
    5. Write a short reflection in `progress/day-15.md`.

    ## Checkpoint
    You are ready to move on when you can explain:
    - What problem this concept solves.
    - One example of when to use it.
    - One common mistake.
