# Day 03 — Functions and modules

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    Functions turn repeated logic into reusable units. A good function has a clear name, inputs, output, and limited responsibility.

Learn positional/keyword arguments, default values, return statements, and imports. Later, your ML project will separate data preparation, training, evaluation and configuration into modules.

    ## Practice loop
    1. Read this lesson once.
    2. Run `starter.py`.
    3. Change one thing and predict what will happen.
    4. Complete the exercises without copying the solution.
    5. Write a short reflection in `progress/day-03.md`.

    ## Checkpoint
    You are ready to move on when you can explain:
    - What problem this concept solves.
    - One example of when to use it.
    - One common mistake.
