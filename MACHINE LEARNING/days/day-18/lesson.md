# Day 18 — K-Means clustering

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    K-Means groups observations by minimizing within-cluster squared distances to cluster centroids.

It requires choosing K and works best when cluster structure is reasonably compatible with distance-based grouping.
