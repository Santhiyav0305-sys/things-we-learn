# Day 16 — Decision trees

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    Decision trees split data into increasingly homogeneous groups. They are intuitive and can model nonlinear relationships.

Trees can overfit when allowed to grow too freely. Hyperparameters such as `max_depth` control complexity.

    ## Practice loop
    1. Read this lesson once.
    2. Run `starter.py`.
    3. Change one thing and predict what will happen.
    4. Complete the exercises without copying the solution.
    5. Write a short reflection in `progress/day-16.md`.

    ## Checkpoint
    You are ready to move on when you can explain:
    - What problem this concept solves.
    - One example of when to use it.
    - One common mistake.
