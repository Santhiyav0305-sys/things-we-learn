# Day 17 — K-nearest neighbors

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    KNN predicts using nearby training examples. Distance matters, so feature scaling is usually important.

K controls how many neighbors vote. Small K can be sensitive to noise; large K creates smoother decisions.
