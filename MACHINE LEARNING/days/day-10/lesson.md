# Day 10 — Normalization and scaling

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    Many algorithms are sensitive to feature scale. Standardization transforms values using `(x - mean) / std`; min-max scaling maps values into a fixed interval.

Tree-based models generally do not require scaling, while distance-based methods and many neural networks benefit from it.
