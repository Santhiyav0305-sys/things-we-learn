# Day 02 — Conditions and loops

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    Programs need decisions and repetition. Use `if/elif/else` for decisions and `for`/`while` for repetition.

Important operators include `==`, `!=`, `<`, `<=`, `>`, `>=`, `and`, `or`, and `not`.

Machine-learning code uses loops less often than beginner Python code because NumPy and Pandas operate on arrays and columns efficiently, but you must understand loops to read and debug code.

    ## Practice loop

    5. Write a short reflection in `progress/day-02.md`.
