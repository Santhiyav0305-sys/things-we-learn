# Day 30 — Feature selection and importance

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    Feature selection removes irrelevant or redundant inputs. Tree models provide importance estimates, while permutation importance asks how performance changes when a feature is shuffled.

Importance is not automatically causality.

    ## Practice loop
    1. Read this lesson once.
    2. Run `starter.py`.
    3. Change one thing and predict what will happen.
    4. Complete the exercises without copying the solution.
    5. Write a short reflection in `progress/day-30.md`.

    ## Checkpoint

    - What problem this concept solves.
