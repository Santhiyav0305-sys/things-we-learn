# Day 32 — Cross-validation

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    Cross-validation repeatedly trains and validates a model on different folds.

It gives a more stable estimate than a single split and is useful for model selection. Keep a final untouched test set when possible.
