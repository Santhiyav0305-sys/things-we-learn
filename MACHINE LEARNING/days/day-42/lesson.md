# Day 42 — RNN concepts and sequence data

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    RNNs process sequences while maintaining a hidden state. They were designed for sequential dependencies, although modern applications often use transformers.

Understand sequence length, hidden state and why long-range dependencies can be difficult.

    4. Complete the exercises without copying the solution.
