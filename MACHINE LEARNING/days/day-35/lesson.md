# Day 35 — How to read an ML paper

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    Research papers use a compressed style. Start with the problem, contribution, method, experiments and limitations.

Do not treat a reported improvement as universally true: check the datasets, baselines, metrics and experimental design.

    ## Practice loop
    1. Read this lesson once.
    2. Run `starter.py`.
    3. Change one thing and predict what will happen.
    4. Complete the exercises without copying the solution.
    5. Write a short reflection in `progress/day-35.md`.

    ## Checkpoint
    You are ready to move on when you can explain:
    - What problem this concept solves.
    - One example of when to use it.
    - One common mistake.
