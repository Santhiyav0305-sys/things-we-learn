# Day 23 — GitHub workflow and README writing

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    GitHub hosts Git repositories and enables collaboration. Learn push/pull, issues, pull requests, and repository documentation.

A strong README explains purpose, setup, data, usage, results and limitations.

    ## Practice loop
    1. Read this lesson once.
    2. Run `starter.py`.
    3. Change one thing and predict what will happen.
    4. Complete the exercises without copying the solution.
    5. Write a short reflection in `progress/day-23.md`.

    ## Checkpoint
    You are ready to move on when you can explain:
    - What problem this concept solves.
    - One example of when to use it.
    - One common mistake.
