# Day 01 — Python environment, variables and types

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    Python is the language used throughout this course. Start with variables, numbers, strings, booleans, `None`, and basic input/output.

A variable is a name pointing to a value. Python is dynamically typed, but every value still has a type.

Core types:
- `int`: whole numbers
- `float`: decimals
- `str`: text
- `bool`: True/False
- `list`: ordered mutable collection
- `dict`: key/value mapping

Use `type(x)` to inspect a value and `help()` or official documentation when learning an API.
