# Day 07 — Data cleaning

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    Real data contains missing values, duplicates, inconsistent categories and incorrect types.

A reliable cleaning process starts with inspection. Never delete rows blindly: understand why values are missing and whether missingness carries information.

    ## Practice loop
    1. Read this lesson once.
    2. Run `starter.py`.
    3. Change one thing and predict what will happen.
    4. Complete the exercises without copying the solution.
    5. Write a short reflection in `progress/day-07.md`.

    ## Checkpoint
    You are ready to move on when you can explain:
    - What problem this concept solves.
    - One example of when to use it.
    - One common mistake.
