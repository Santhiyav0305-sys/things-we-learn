# Day 38 — Neural-network intuition

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    A neural network combines weighted inputs, biases and nonlinear activation functions.

A single neuron computes `activation(w·x + b)`. Multiple neurons and layers can represent increasingly complex functions.

    ## Practice loop
    1. Read this lesson once.
    2. Run `starter.py`.
    3. Change one thing and predict what will happen.
    4. Complete the exercises without copying the solution.
    5. Write a short reflection in `progress/day-38.md`.

    ## Checkpoint
    You are ready to move on when you can explain:
    - What problem this concept solves.
    - One example of when to use it.
    - One common mistake.
