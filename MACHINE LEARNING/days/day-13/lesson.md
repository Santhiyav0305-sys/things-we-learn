# Day 13 — Train/validation/test and leakage

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    A test set is for final evaluation. A validation set helps select models or settings. Cross-validation is often used when data is limited.

Data leakage occurs when information unavailable at prediction time influences training. Leakage can produce misleadingly high scores.
