# Day 09 — Exploratory Data Analysis

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    EDA is structured curiosity. Inspect shape, types, missingness, distributions, relationships and suspicious observations.

For every important finding, ask: Could this pattern be caused by data collection, leakage, sampling or measurement?

    ## Practice loop
    1. Read this lesson once.
    2. Run `starter.py`.
    3. Change one thing and predict what will happen.
    4. Complete the exercises without copying the solution.
    5. Write a short reflection in `progress/day-09.md`.

    ## Checkpoint
    You are ready to move on when you can explain:
    - What problem this concept solves.
    - One example of when to use it.
    - One common mistake.
