# Day 34 — Model evaluation and error analysis

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    A single metric does not explain why a model fails. Inspect residuals, confusion matrices, subgroup performance and representative mistakes.

Ask whether errors are random, systematic, or caused by data quality.

    ## Practice loop
    1. Read this lesson once.
    2. Run `starter.py`.
    3. Change one thing and predict what will happen.
    4. Complete the exercises without copying the solution.
    5. Write a short reflection in `progress/day-34.md`.

    ## Checkpoint
    You are ready to move on when you can explain:
    - What problem this concept solves.
    - One example of when to use it.
    - One common mistake.
