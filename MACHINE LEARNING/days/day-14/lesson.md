# Day 14 — Linear regression

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    Linear regression models a continuous target as a weighted combination of features.

Start with one feature, then multiple features. Learn coefficients, intercept, residuals and MAE/RMSE/R².

    ## Practice loop
    1. Read this lesson once.
    2. Run `starter.py`.
    3. Change one thing and predict what will happen.
    4. Complete the exercises without copying the solution.
    5. Write a short reflection in `progress/day-14.md`.

    ## Checkpoint
    You are ready to move on when you can explain:
    - What problem this concept solves.
    - One example of when to use it.
    - One common mistake.
