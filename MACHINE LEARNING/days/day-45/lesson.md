# Day 45 — Capstone planning, presentation and handoff

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    Day 45 is the integration checkpoint. Plan the separate capstone: define the problem, data, target, success metric, baseline, risks and milestones.

A good presentation tells a reproducible story: problem → data → method → results → errors → limitations → next steps.

    ## Practice loop
    1. Read this lesson once.
    2. Run `starter.py`.
    3. Change one thing and predict what will happen.
    4. Complete the exercises without copying the solution.
    5. Write a short reflection in `progress/day-45.md`.

    ## Checkpoint
    You are ready to move on when you can explain:
    - What problem this concept solves.
    - One example of when to use it.
    - One common mistake.
