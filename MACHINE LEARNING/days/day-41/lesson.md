# Day 41 — CNN concepts and image classification

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    Convolutional neural networks use local receptive fields and shared filters. Pooling or strided operations can reduce spatial resolution.

For an image task, inspect the dataset, normalize inputs, build a baseline, train, validate and inspect incorrect predictions.

    ## Practice loop

    4. Complete the exercises without copying the solution.
