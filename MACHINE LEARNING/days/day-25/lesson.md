# Day 25 — Saving and loading models

## Objective
By the end of today, you should be able to explain the main idea and use it in a small program.

## Lesson
A trained model can be serialized with joblib. Saving a model is useful only when you also save the preprocessing assumptions, feature names, library versions and evaluation results.

## Practice loop
1. Read this lesson once.
2. Run `starter.py`.
3. Change one thing and predict what will happen.
4. Complete the exercises without copying the solution.
5. Write a short reflection in `progress/day-25.md`.
