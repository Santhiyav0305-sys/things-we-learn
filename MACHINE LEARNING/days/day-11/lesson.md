# Day 11 — What is machine learning?

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    Machine learning learns patterns from examples to make predictions or decisions.

A model is a parameterized function. Training estimates parameters from data. Evaluation measures performance on data the model did not use to fit those parameters.

    ## Practice loop
    1. Read this lesson once.
    2. Run `starter.py`.
    3. Change one thing and predict what will happen.
    4. Complete the exercises without copying the solution.
    5. Write a short reflection in `progress/day-11.md`.

    ## Checkpoint
    You are ready to move on when you can explain:
    - What problem this concept solves.
    - One example of when to use it.
    - One common mistake.
