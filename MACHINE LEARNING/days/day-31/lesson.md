# Day 31 — PCA

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    Principal Component Analysis creates new orthogonal directions that capture variance.

PCA is useful for compression and visualization, but components can be difficult to interpret. Standardize features when scale differences would otherwise dominate.
