# Day 05 — NumPy arrays

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    NumPy provides fast numerical arrays. Learn array creation, shape, dtype, indexing, slicing, vectorized arithmetic, boolean masks, `mean`, `std`, `min`, `max`, and matrix multiplication.

The key idea is vectorization: express operations on whole arrays rather than writing Python loops for every element.

    4. Complete the exercises without copying the solution.
