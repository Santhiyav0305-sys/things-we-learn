# Day 04 — Collections

    ## Objective
    By the end of today, you should be able to explain the main idea and use it in a small program.

    ## Lesson
    Lists, tuples, dictionaries and sets are core Python containers.

Use lists for ordered collections, dictionaries for named values, tuples for fixed groups, and sets for unique items.

List comprehensions are useful, but readability matters more than cleverness.
