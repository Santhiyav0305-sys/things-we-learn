# Day 06 — Pandas Series and DataFrames

## Objective
By the end of today, you should be able to explain the main idea and use it in a small program.

## Lesson
Pandas is the main tool for tabular data. Learn `read_csv`, `head`, `info`, `describe`, selecting columns, filtering rows, sorting, `groupby`, and creating new columns.

## Practice loop
1. Read this lesson once.
2. Run `starter.py`.
3. Change one thing and predict what will happen.
4. Complete the exercises without copying the solution.
5. Write a short reflection in `progress/day-06.md`.

## Checkpoint
You are ready to move on when you can explain:
- What problem this concept solves.
- One example of when to use it.
- One common mistake.
