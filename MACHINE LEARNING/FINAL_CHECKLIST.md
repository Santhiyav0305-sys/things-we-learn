# 45-Day Completion Checklist

## Foundations
- [ ] I can write basic Python without a tutorial.
- [ ] I can manipulate arrays with NumPy.
- [ ] I can load, clean and analyze a CSV with Pandas.
- [ ] I can create useful plots.

## ML
- [ ] I understand train/test splitting and leakage.
- [ ] I can train regression and classification models.
- [ ] I can use a decision tree and K-Means.
- [ ] I can explain overfitting.
- [ ] I can select appropriate metrics.

## Engineering
- [ ] I can use Git.
- [ ] I can organize an ML repository.
- [ ] I can save/load a model.
- [ ] I can track experiments.
- [ ] I can write basic tests.

## Advanced
- [ ] I can engineer features.
- [ ] I can build preprocessing pipelines.
- [ ] I understand PCA.
- [ ] I can run cross-validation.
- [ ] I can tune hyperparameters.
- [ ] I can perform error analysis.
- [ ] I can read an ML paper.

## Deep learning
- [ ] I understand a neural-network forward pass.
- [ ] I understand loss and gradient descent.
- [ ] I have implemented a tiny network with NumPy.
- [ ] I understand CNN and RNN concepts.
- [ ] I can describe a practical deep-learning workflow.

## Capstone
- [ ] Problem defined
- [ ] Data documented
- [ ] Baseline built
- [ ] Model evaluated
- [ ] Errors analyzed
- [ ] Limitations documented
- [ ] Repository reproducible
- [ ] Presentation prepared
