# Mini Project 2 — Customer Segmentation

Use `data/customers.csv` to explore customer groups.

## Minimum workflow
1. Inspect data.
2. Scale numeric features.
3. Try K=2..6.
4. Compare cluster sizes and within-cluster behavior.
5. Use PCA for a 2D visualization.
6. Describe clusters without claiming that the clusters are objectively "real" customer types.
