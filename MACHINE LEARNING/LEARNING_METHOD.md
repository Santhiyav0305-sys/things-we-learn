# How to Learn Effectively

## Daily 90–150 minute routine

**20 min — Learn**
- Read the day's lesson.
- Explain each concept in your own words.

**40–60 min — Code**
- Run the starter.
- Change values and break the code intentionally.
- Rebuild key examples without copy/paste.

**30–45 min — Practice**
- Complete exercises.
- Do at least one exercise from memory.

**10 min — Reflect**
Answer:
1. What did I learn?
2. What confused me?
3. What can I explain without notes?
4. What will I practice tomorrow?

## The 3-pass rule

1. **Understand:** What problem does this tool solve?
2. **Implement:** Can I use it on a small dataset?
3. **Explain:** Can I explain the result to another beginner?

## When you get stuck

Use this sequence:

1. Read the error message.
2. Print the variables involved.
3. Reduce the problem to 5–10 lines.
4. Search the official documentation.
5. Compare with the solution only after attempting the problem.

## Avoid tutorial hell

For every concept, create something:
- Python → small CLI program
- Pandas → data report
- Regression → prediction model
- Classification → confusion matrix
- Clustering → customer segments
- Neural network → image/text mini project
